- 結果（比較表や数字）： 学習前：`format_rate` =　14.3%（3/21） / `content_rate` =0.0%　/seconds = 33.4秒
- 学習後：`format_rate` =　100.0% / `content_rate` =100.0%　/ seconds = 87.9秒
- ファインチューニングが向く場面・向かない場面についての考察：向く場面としては、未知の質問に対する判断ルールの学習である。FAQ に根拠がない場合に「無理に答えず needs_review: true を返す」というメタ的な判断・応答パターンを叩き込む用途として適していると考えられる。また、向かない場面としては、知識の動的書き換えの場面である。FAQの内容が更新された場合、再度その内容自体を学習する必要があり非効率である。
